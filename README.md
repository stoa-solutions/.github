# Stoa · Profil GitHub

Ce dépôt contient la présentation publique de l’organisation [stoa-solutions](https://github.com/stoa-solutions).
GitHub affiche `profile/README.md` sur son accueil.

## Modifier la présentation

- Texte et liens : `profile/README.md`.
- Bannière affichée : `profile/assets/stoa-github-banner.png` (1600 × 680).
- Composition éditable : `design/banner.html`.
- Logo : `profile/assets/stoa-logo-encre.svg`, tracés officiels de Stoa.
- Matière architecturale et polices : `design/`.

Pour régénérer la bannière, ouvrir `design/banner.html` dans un navigateur avec une fenêtre de 1600 × 680 pixels, attendre le chargement des polices et exporter cette zone en PNG. La composition utilise Manrope et IBM Plex Mono, embarquées avec leurs licences OFL.

L’aperçu Sillage reprend la capture publique `stoa-solutions/sillage/main/docs/images/sillage.webp` dans une enveloppe SVG : un masque arrondi rend les coins transparents sans retoucher les pixels de l’interface. Après une mise à jour de la capture, régénérer cette enveloppe et vérifier les modes clair et sombre.

## Identité et contenus

Les logos, noms et visuels de marque Stoa et Sillage ne sont pas proposés sous une licence open source. Les licences des polices sont incluses dans `design/`. Les licences des projets logiciels sont définies dans leurs dépôts respectifs.

Ne pas ajouter de documents de travail internes, de secrets ou de données utilisateur dans ce dépôt public.
